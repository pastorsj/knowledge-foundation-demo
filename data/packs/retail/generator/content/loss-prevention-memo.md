Effective **August 15, 2026** the controls below apply in every store, and the stores named in section 3 move to
enhanced return monitoring. This memo supplements the Return and Refund Policy (POL-RET-014) and replaces memo
AP-2026-018.

## 1. No-receipt returns

A return with no receipt, order number or Rewards ID lookup is limited to **$75.00 per transaction** and is refunded as
**store credit only**. A customer may make no more than **3 no-receipt returns in any rolling 90 days**. The cashier
scans the customer's photo ID into the return screen for every no-receipt return.

## 2. Manager approval

A Store Manager must approve, with an override code: any return over **$250.00**; any Electronics return where the
serial number was not captured; and a third return by the same customer within 30 days.
