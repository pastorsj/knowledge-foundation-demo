# data

The industry packs and their schemas. There is no builder here: the `ingest` service reads `data/packs/` (mounted
read-only at `/packs`) and ingests every pack through the same pipeline as an upload
([ingestion](../docs/ingestion.md#pack-sync)). [Data packs](../docs/data-packs.md) is the full guide.

```text
data/
  packs/<id>/              one industry
    pack.yaml              identity, licenses, provenance, sources, declared keys, prediction templates
    questions.yaml         questions with tool pills, the picker's examples, conversations
    files/                 the synthetic files the sources' globs name (PDF, DOCX, PPTX, PNG, CSV, XLSX)
    generator/build.py     the seeded script that writes files/ and README.md
    generator/content/     the authored text it renders
    recordings/            replay bundle v2 (written by ./scripts/demo.sh record --pack <id>)
    README.md              data card and answer key
  schemas/
    pack.schema.json       pack.yaml, schema version "3"
    questions.schema.json  questions.yaml, schema version "3"
```

## Packs

| Pack | Company | Sources |
|---|---|---|
| [`retail`](packs/retail/README.md) | Lumen Retail Group | `sales` (structured), `policies`, `reports` |
| [`manufacturing`](packs/manufacturing/README.md) | Atlas Precision Components | `operations` (structured), `procedures`, `reports` |
| [`healthcare`](packs/healthcare/README.md) | Riverside Health Network | `clinical` (structured), `guidelines`, `operations` |
| [`financial-services`](packs/financial-services/README.md) | Harborview Community Bank | `banking` (structured), `policies`, `disclosures` |

Everything in every pack is synthetic and generated by its own script. The catalog names each source
`<pack>.<source>` (`retail.sales`).

## Commands

```bash
./scripts/demo.sh data validate           # every pack against the schemas, plus the cross-file rules
./scripts/demo.sh data generate retail    # regenerate a pack's files from its generator (uv on the host)
./scripts/demo.sh data sync               # ingest the packs whose files changed, on a running stack
./scripts/demo.sh data status             # each pack's ingestion status
```

`data validate` runs [`scripts/validate_packs.py`](../scripts/validate_packs.py); ingest validates the same schemas
when it syncs. Change a pack through its generator, never by editing `files/` by hand.
